### Hi, I'm Bob 👋

I build tools that make AI coding agents easier to watch, steer and trust — mostly for [OpenCode](https://opencode.ai), in TypeScript.

#### 🛠 What I'm working on

**[opendeck](https://github.com/ptthien97/opencode-opendeck)** — a live mission-control dashboard for the OpenCode TUI: context gauge, a live tree of running subagents, pending approvals, git and files changed per agent, diff and usage pages.

<a href="https://github.com/ptthien97/opencode-opendeck"><img src="https://raw.githubusercontent.com/ptthien97/opencode-opendeck/master/docs/demo.gif" alt="opendeck demo" width="640"></a>

```bash
opencode plugin add github:ptthien97/opencode-opendeck
```

**[opencode-kit](https://github.com/ptthien97/opencode-kit)** — back up and restore a whole OpenCode setup on a new machine with one command, with a role-based model picker.

#### 🧰 Stack

TypeScript · Solid · Bun · Dart / Flutter · Python · shell
